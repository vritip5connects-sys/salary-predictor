# 💼 Salary Predictor

I built this project to understand how experience and skills can affect salary.

## What it does

- Takes experience and skills as input  
- Predicts salary using a simple regression model  
- Shows a graph of salary vs experience  
- Explains which factor has more impact  

## Why I made this

I wanted a simple way to see how salary can change based on profile strength instead of just guessing.

## Tech used

- Python  
- Scikit-learn  
- Streamlit  
- Matplotlib  

## How to run

pip install scikit-learn streamlit matplotlib  

streamlit run app.py
