 # 💼 Salary Predictor

I built this project to understand how experience and skills affect salary.

## What it does

- Takes experience and skills as input  
- Predicts salary using a simple ML model  
- Shows a graph of salary vs experience  
- Explains which factor affects salary more  

## Why I made this

I wanted a simple way to understand how different factors impact salary instead of guessing.

## Tech used

- Python  
- Scikit-learn  
- Streamlit  
- Matplotlib  

## How to run

pip install scikit-learn streamlit matplotlib  

streamlit run app.py
